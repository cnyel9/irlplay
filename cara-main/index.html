Cara Main IRLPlay

Apa itu IRLPlay?

IRLPlay adalah Website game yang mengubah aktivitas sehari-hari menjadi petualangan seru! ✨ Setiap aktivitas yang kamu lakukan akan memberikan XP dan hadiah menarik. Mulai dari olahraga, belajar, sampai bersosialisasi, semuanya bisa jadi misi yang seru! Level up kehidupanmu!

XP & Level System

  • Setiap misi memberikan 10-50 XP Points
  • Level up setiap 100 × level XP
  • Bonus koin & fitur baru tiap naik level

Streak System

  • Main tiap hari untuk jaga streak
  • Bonus XP: +5% per hari streak
  • Streak Freeze untuk jaga streak

Achievement System

  • Prestasi spesial dengan hadiah keren
  • Bonus koin untuk setiap achievement
  • Fitur eksklusif saat capai prestasi

Shop System

  • Double XP Boost (30 menit)
  • Streak Freeze (1 hari)
  • Item spesial lainnya

Cara Mulai Main

  1. Buka halaman Beranda
  2. Pilih misi yang tersedia
  3. Selesaikan misi di dunia nyata
  4. Klik "Selesai" untuk dapat XP
  5. Kumpulkan streak untuk bonus
  6. Beli item di Shop pakai koin
  7. Level up untuk fitur baru!

Cara Apply Misi

  • Pilih misi yang tersedia di halaman utama
  • Klik tombol "Mulai Misi"
  • Lakukan misi di dunia nyata
  • Upload bukti foto kegiatan
  • Tunggu verifikasi dari sistem

Penting Diingat!

  • Misi harus diselesaikan dalam 24 jam
  • Bukti foto harus jelas dan sesuai misi
  • Misi gagal jika tidak upload bukti
  • Tidak bisa apply misi baru saat ada misi aktif
